# Getting Started

The quick start guides help you explore OpenNHP through a working environment and follow the interaction between its components. Choose an NHP guide to try access to a protected network service, or the DHP guide to explore data protection.

In the NHP flow, an agent sends an encrypted knock to a server. The server authenticates and authorizes the request, asks an access controller to permit access, and returns the result to the agent. Following this flow in a test environment provides a foundation for understanding a larger deployment.


After completing a quick start, continue to [Deployment]({% link deployment.md %}) for guidance on running binaries and arranging server instances.
