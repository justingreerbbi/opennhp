# Technical Reference

This section describes the cryptography and wire format used by OpenNHP. It supports readers who need to understand packet processing, implement a compatible client, or investigate protocol behavior in detail.

Use the cryptography guide to understand the supported algorithms and the protocol reference to examine message headers and message types. The reference connects protocol concepts to their implementation in the codebase.
