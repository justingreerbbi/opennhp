# Deployment

Deploying OpenNHP involves choosing where its components run, configuring their identities and peers, and connecting them to the resources they protect. In a typical NHP deployment, agents request access, servers make authentication and authorization decisions, and access controllers manage the network rules that permit access.

This section covers running OpenNHP binaries and understanding deployments with multiple server instances. Use it after a quick start, when you are ready to consider how the components fit into your own environment.


To compile the components yourself, see [Build from Source]({% link build.md %}).
