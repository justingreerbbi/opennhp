# Overview

OpenNHP is a Zero Trust security toolkit built around two protocols: NHP (Network-infrastructure Hiding Protocol) and DHP (Data-content Hiding Protocol). NHP conceals protected network resources from unauthorized access, while DHP focuses on protecting data through encryption and confidential computing.

This section introduces the project, its capabilities, and the terminology used throughout the documentation. Start here to understand what OpenNHP does before trying a quick start or planning a deployment.
