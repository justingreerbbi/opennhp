# Development

OpenNHP provides protocol libraries, daemon implementations, client SDKs, and a server plugin interface. These allow contributors to work on the core toolkit and developers to connect applications or authentication services to an OpenNHP deployment.

This section introduces the source tree and the main extension points. Start with the build and code guides if you are new to the repository, then choose an SDK or plugin guide based on the integration you want to develop.


For cryptographic details and packet formats, consult [Technical Reference]({% link technical-reference.md %}).
